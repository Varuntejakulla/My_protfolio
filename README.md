# 👨🏻‍💻 AI Engineer & Python Developer Portfolio

A modern, high-performance portfolio built with **Next.js, TypeScript, Tailwind CSS, and Framer Motion**. Designed to showcase my work in **AI/ML, Generative AI, Python development, RAG, and AI agentic systems** with smooth animations and a responsive design.

![AI Engineer Portfolio Screenshot](./public/images/screenshot.png)

### 🌐 Live Portfolio

[Visit My Portfolio](https://varun-kulla.vercel.app/)

---

## ✨ Features

* 🤖 **AI Engineer Portfolio** – Showcase AI, ML, GenAI, and agentic AI projects
* 🎨 **Modern UI** – Clean dark-themed interface with gradient effects
* ✨ **Smooth Animations** – Interactive animations powered by Framer Motion
* 📱 **Fully Responsive** – Optimized for mobile, tablet, and desktop
* ⚡ **High Performance** – Built with Next.js for fast page loading
* 🧩 **Easy Customization** – Update projects, skills, experience, and personal information easily
* 🌌 **Interactive Design** – Modern hover effects, animated elements, and transitions

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Varuntejakulla/web-dev-portfolio.git
```

Navigate to the project:

```bash
cd web-dev-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
